Privacy Policy

更新日期：2026 年 9 月 15 日

本政策适用于 booiris 维护的 Baybo 个人 Gmail 只读集成。该应用供维护者本人使用，不提供公众注册服务。联系邮箱：booiris02@gmail.com。

1. 访问哪些数据

应用通过 Google OAuth 获取授权，不要求用户向应用提供 Google 密码。登录流程可访问基本身份信息（如邮箱地址和个人资料）。Gmail 集成申请 https://www.googleapis.com/auth/gmail.readonly，该权限允许读取邮件及其元数据，包括邮件 ID、线程 ID、标签、发件人、收件人、主题、日期、正文，以及在明确请求时读取的附件。

日常简报按配置搜索时间范围内的未读邮件，先检查元数据，再选择相关邮件读取正文；不默认下载全部附件。只读权限本身并不限于这些筛选条件。

2. 数据用途

邮件数据用于用户请求的邮件检索、重要性分类、中文摘要、原邮件链接展示及重复通知去重。不用于广告定向、出售数据或建立与此功能无关的用户画像。此 Gmail 集成不发送、删除、归档邮件，也不标记已读。

3. AI 处理与第三方服务

应用通过 Google API 读取邮件，自托管 Baybo 服务负责协调处理。为完成分类和摘要，相关邮件元数据及正文可能被传递给部署中配置的第三方 AI 模型服务。因此，邮件处理并非完全离线，数据可能在用户所在地以外处理。

AI 服务的具体提供方取决于运行时配置；其日志、保留及数据处理规则受所使用服务及账户设置约束。本页面不承诺第三方服务零保留。维护者应在启用相关服务前确认其条款及数据使用设置符合授权目的和 Google API 数据政策。不主动将 Gmail 数据用于训练通用 AI 模型。

4. 存储与保护

Google OAuth 凭据在自托管部署中加密保存，运行所需密钥由凭据管理机制提供，不发布到本网站或源代码仓库。应用使用 HTTPS 与 Google 及远程服务通信。

每日邮件检查的去重状态仅保存扫描时间、已检查或已报告的邮件 ID 和必要分类，不保存邮件正文、验证码或令牌。但邮件读取工具的返回结果、AI 输入及摘要可能出现在 Baybo 会话记录、执行追踪或配置的模型服务日志中；去重文件不存正文并不代表整个处理链路不保留正文。

5. 保留与删除

本部署目前没有统一的自动到期删除承诺。OAuth 凭据、去重状态及运行记录可能保留至维护者主动清理；第三方服务的副本依其保留规则处理。可通过联系邮箱请求停止任务并清理自托管部署中的相关凭据、状态和会话记录。第三方日志或备份未必能即时删除。

6. 撤销授权

用户可以随时在 Google 账号的第三方连接管理页面撤销 Baybo 的访问权限。撤销后应用不能继续使用该授权访问 Gmail；撤销授权不会自动删除此前生成的简报或本地记录，需要另行清理。

7. Google API 数据使用

Baybo 对从 Google API 获取的信息的使用及向其他应用的传输须遵守 Google API Services User Data Policy，包括 Limited Use 要求。数据处理应限于提供用户授权的邮件功能，不用于广告、出售数据或训练通用 AI 模型。

8. 网站与政策变更

这些说明页托管于 GitHub Pages，页面本身不嵌入分析脚本、广告或追踪像素；托管服务仍可能处理访问所必需的网络日志。若应用的数据处理方式发生变化，维护者将更新本页及更新日期。
